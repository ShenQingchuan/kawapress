# Reference site

Every official UI plugin is installed in this site, but the theme is the small
reference theme from `e2e/fixtures/reference-theme`. Nothing here comes from a
preset.

::: tip
A tip container paints itself from the plugin stylesheet and the public tokens.
:::

::: info
The info container takes its accent from the brand token.
:::

> [!NOTE]
> A GitHub alert keeps its own title, icon and colours without a preset.
