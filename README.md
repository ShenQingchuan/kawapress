<h1 align="center">KawaPress</h1>

KawaPress is a Vue-centric static site generator for content-focused websites. It compiles Markdown into a Vue application with SSR, hydration, file-based routing, and extensible generator and runtime plugins.

KawaPress 是一个以 Vue 为核心、面向内容型网站的静态站点生成器。它将 Markdown 编译为支持 SSR、hydration、文件路由以及生成侧与运行侧插件扩展的 Vue 应用。

## Development / 开发

```bash
pnpm install
pnpm build
pnpm lint
pnpm typecheck
pnpm test
```

KawaPress is currently under active development.

KawaPress 目前仍在积极开发中。
